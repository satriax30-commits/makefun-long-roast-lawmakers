A make.fun bounty entry: one satirical sentence roasting lawmakers who would
write the rules for artificial intelligence, crypto, or the internet — yet
cannot convert a file to PDF. The program writes that single sentence to
`/output/entry.txt`, guarded to the competition's gate (UTF-8 text, 1–320
characters, one line, one sentence) and verified byte-identical on read-back.

## How to run

```sh
node main.ts
```

Node 22, standard library only. Deterministic: no clock, no randomness, no
network — the same entry, byte for byte, every run.
